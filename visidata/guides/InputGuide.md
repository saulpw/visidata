# Input keystrokes

Keystrokes available at any input prompt.

## Submit and cancel

- `Enter` to accept input
- `Ctrl+C` or `Esc` to abort input

## Edit the input

- `Bksp` or `Ctrl+H` to delete the character before the cursor
- `Del` or `Ctrl+D` to delete the character at the cursor
- `Ctrl+W` or `Alt+Bksp` to delete the word before the cursor
- `Ctrl+Del` or `Alt+Del` to delete the word after the cursor
- `Ctrl+U` to clear to the beginning of the line
- `Ctrl+K` to clear to the end of the line
- `Ctrl+T` to transpose the two characters around the cursor
- `Ctrl+R` to restore the starting value
- `Ctrl+O` to open the input in `$EDITOR`
- `Ins` to toggle insert/overwrite mode
- `Ctrl+V` to insert the next keystroke as a literal character
- `Ctrl+N` then a keystroke, to insert that keystroke's spelled-out name
- `Ctrl+Y` to paste from the memory clipboard

## Move the cursor

- `Left`/`Right` or `Ctrl+B`/`Ctrl+F` to move one character
- `Ctrl+Left`/`Ctrl+Right` to move one word
- `Home`/`End` or `Ctrl+A`/`Ctrl+E` to jump to the start or end of the line

## History and completion

- `Up`/`Down` to cycle previous inputs for this input type
- `Tab`/`Shift+Tab` to cycle completions

## Other

- `Ctrl+G` to cycle sidebar help panes
- `Ctrl+Z` to suspend VisiData
